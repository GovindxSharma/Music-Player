
## 🎧 Music Player – Static Frontend UI

A stylish and modern **music player frontend UI** built using **HTML, CSS, and JavaScript**. This project features a fully designed music dashboard with playlist visuals, genre covers, and a responsive layout — perfect for showcasing frontend development skills.

---

## 🔗 Live Demo

👉 [View Live](https://music-player-pa29.onrender.com)

---

## ✨ Features

* 🎨 **Beautiful UI design** with genre and artist images
* 📱 **Fully responsive layout** (mobile + desktop)
* 🖼️ Rich image assets for songs, playlists, and themes
* 📂 Organized structure for easy extension
* 🚫 No backend/audio logic – design-focused project only

---

## 📁 Folder Structure

```
Music-Player/
│
├── index.html              # Main HTML file
├── styles.css              # Main styling file
├── mediaqueries.css        # Responsive styles
├── script.js               # JS for interactive behavior (if any)
├── images/                 # Album art, artist images, UI graphics
│   ├── 1.jpg, 2.jpg, ...   # Genre or artist thumbnails
│   └── logo.jpg, retro.png, stations-img.png, etc.
├── package.json            # For sandbox/boilerplate (if used)
└── sandbox.config.json     # (Optional config, e.g., for CodeSandbox)
```

---

## 🧪 How to Run Locally

```bash
git clone https://github.com/GovindxSharma/Music-Player.git
cd Music-Player
open index.html   # or just double-click the file
```

> No frameworks or setup needed — it's a static frontend project.

---

## 🛠 Tech Stack

* **HTML5** – Page structure
* **CSS3** – Styling, layout, and responsiveness
* **JavaScript** – UI behavior (optional light logic)
